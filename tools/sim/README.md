# Симуляция баланса «Династии»

Небольшая симуляция на чистом Python: стандартная библиотека, без установки пакетов. Отвечает на два вопроса: укладываются ли бои в потолок «перевес не больше 70%» и укладывается ли партия в 30–40 минут. Результаты — в [REPORT.md](REPORT.md).

## Запуск

```bash
cd tools/sim
python3 -m unittest      # 23 теста: геометрия замка, правила боёв, партия
python3 report.py        # пересчитать таблицы отчёта, около минуты
```

## Файлы

- `castle.py` — замок-воронка из `location.md`: 27 комнат без тупиков, четверо ворот, коридор. Здесь же случайные стены с гарантиями из дизайна: путь к граалю и два независимых пути от воронки до каждых ворот.
- `fights.py` — 12 боёв из «Двенадцати боёв». Числа, которых нет в правилах, вынесены в начало файла. `CALIBRATED` — подобранные бонусы.
- `match.py` — партия по правилам первого прототипа. Тайминги и предположения о поведении игроков — в начале файла.
- `report.py` — собирает таблицы для отчёта.
- `test_*.py` — тесты.
