# Макеты игры

Все изображения ожидают визуального контроля. Это авторские концепты для обсуждения; направление, способности и внешний вид игры ещё не утверждены. Номер версии не означает одобрение.

15 направлений игровых экранов; у №03 и №12 сохранены обе версии — всего 17 PNG. №13–15 исследуют стилизации за пределами исходного пиксельного направления.

## Происхождение

PNG-концепты созданы для Project Dino через image_gen. Чужие изображения не включены. Изображения не перерисовывались и не перекодировались.

[Манифест файлов](manifest.json) содержит относительные пути происхождения и статус визуального контроля.
