# Картинки

Здесь лежат наши собственные картинки к дизайн-документу: эскизы и концепты, макеты экранов, пиксель-арт, скриншоты нашей игры.

Чужие референсы — скриншоты других игр, картинки из интернета — сюда не кладём, потому что репозиторий публичный. Для них есть доска в Miro, ссылка на неё — в [visual.md](../visual.md).

## Как добавлять

- Формат: PNG для пиксель-арта и скриншотов. JPG — для фотографий бумажных набросков и картинок, которые помогают обсудить внешний вид игры.
- Имя: латиница, строчные буквы и дефисы. В начале имени — раздел: `heroes-wings.png`, `location-room-types.png`, `gameplay-…`, `visual-…`.
- Размер: держим файлы маленькими, не больше нескольких мегабайт. Исходники Aseprite и PSD и видео сюда не кладём: каждая версия файла навсегда остаётся в истории git.
- Картинку добавляем в том же PR, что и текст, где она используется.

## Как вставить в документ

В файле из `docs/design/`:

```markdown
![Динозавр с крыльями](images/heroes-wings.png)
```
