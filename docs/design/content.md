# Содержимое первого прототипа

Конкретные части тела, предметы, события, монстры и сундуки, из которых собирается первый прототип. Правила — в [Героях](heroes.md), [Локации](location.md) и [Геймплее](gameplay.md), числа — в «Числах прототипа» (`numbers.md`, ветка правок по раскадровке).

## Что придумали

Решено 2026-10-06.

### Части тела

По 2 на характеристику. Каждая часть даёт +1 к своей характеристике и одно действие на карте. Пять частей уже были в `heroes.md`, три новые отмечены ★.

| Часть тела | Характеристика | Действие на карте |
|---|---|---|
| Длинные ноги | Скорость | Раз за ход перебросить кубик движения |
| Крылья | Скорость | Перелететь преграду, не останавливаясь |
| Рога | Сила | Сломать баррикаду или завал |
| ★ Мощные челюсти | Сила | Порог против слабого монстра на 1 ниже |
| Пластины | Броня | Ловушки отнимают вдвое меньше |
| ★ Панцирь | Броня | Откат после события или ловушки не действует |
| Гребень | Хитрость | В лавке 4 предложения вместо 3 |
| ★ Чуткий нос | Хитрость | Раз за ход открыть всем, что за одной из дверей |

### Аксессуары

По 2 на характеристику, каждый даёт +2. Мест три: голова, шея, спина.

| Голова | Шея | Спина |
|---|---|---|
| Диадема (хитрость) | Ожерелье из зубов (броня) | Знамя дома (сила) |
| Рогатый шлем (сила) | Шарф гонщика (скорость) | Плащ-невидимка (хитрость) |
| Перо-флюгер (скорость) | | Седло-щит (броня) |

### Разовые предметы

| Предмет | Цена, золотых | Что делает |
|---|---|---|
| Ловушка | 2 | Неточная ловушка в выбранную сторону |
| Баррикада | 3 | Закрывает дверь на 2 круга |
| Карта | 2 | Открывает план замка на 2 комнаты вокруг |
| Зелье | 3 | +2 к одной характеристике на один бой |
| ★ Дымовая шашка | 3 | Один раз пройти сквозь соперника без встречи. Инструмент побега для носителя грааля |

### События

У каждого рискованный вариант и осторожный. Рискованный — бросок 4+ с характеристикой события, награда 5 золотых. Осторожный — 1 золотой.

| Событие | Характеристика | Рискованно | Осторожно |
|---|---|---|---|
| Яма с кольями | Скорость | Прыгнуть | Обойти |
| Доисторическая курица | Скорость | Обогнать её до кормушки | Уступить дорогу |
| Застрявший сундук | Сила | Выломать крышку | Ковырять ножом |
| Турнир манекенов | Сила | Сбить манекен с коня | Поклониться ему |
| Мост из костей | Броня | Идти по мосту, провал — откат | Брод |
| Падающая люстра | Броня | Принять на спину и забрать хрусталь | Увернуться |
| Спящий привратник | Хитрость | Стащить его кошель, провал −2 | Не будить |
| Говорящий портрет | Хитрость | Переспорить его — разовый предмет | Польстить |
| Фонтан желаний | — | Бросить 2 золотых: на 5+ получить 6 | Пройти мимо |
| Книга Летописца | — | Вписать себя в историю: +1 к любой характеристике до конца партии, но −3 золотых | Полистать: +1 золотой |

### Монстры

**Слабые** нужны для антуража: правила у всех одинаковые, различаются только характером и картинкой. Барон Плесень, Крыса-оруженосец, Кусачий плед, Скелет-неудачник, Пыльный дракончик, Ворчливые доспехи.

**Сильные.** У каждого одна главная характеристика. Ближе к граалю её уровень выше, от 3 до 5.

| Сильный монстр | Главная характеристика | Характер |
|---|---|---|
| Сэр Гнилозуб, страж кладовки | Сила | Ест всё, включая ваши аргументы |
| Леди Мокрица | Броня | Сворачивается в шар при любом намёке на бой |
| Граф Сквозняк | Скорость | Носится по залам и хлопает дверьми |
| Шут-Хамелеон | Хитрость | Притворяется дверью |
| Страж грааля | Все по 3 | Стоит в коридоре в короне. Корону отдавать не собирается |
