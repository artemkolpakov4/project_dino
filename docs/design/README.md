# project_dino — дизайн игры

Пошаговая пиксельная игра для компании до 4 человек на одном телевизоре. Динозавры исследуют случайно сгенерированный замок, ищут грааль и несут его к выходу, а остальные пытаются им помешать.

Документ ведём вдвоём с Олегом. Пока здесь только первые наработки. В каждом файле три раздела: что придумали, вопросы, идеи.

- [Геймплей](gameplay.md)
